# Calibrated scientific language

| Evidence situation | Prefer | Avoid |
|---|---|---|
| Direct measurement | “The measured value was…” | “This proves…” |
| Model-dependent output | “The fit estimated…” | “The true value is…” |
| Pattern/reference agreement | “Consistent with…” | “Confirms” without exclusion of alternatives |
| Association | “Was associated with…” | “Caused…” |
| Below detection | “Was not detected above…” | “Was absent” |
| Limited sample | “In the measured samples…” | Universal generalization |
| Competing explanations | “May reflect X; Y remains possible” | Single-mechanism certainty |

Each quantitative claim should include units, comparison baseline, uncertainty or interval where available, and the evidence node that supports it. Each literature claim needs a real, verified citation; never synthesize a plausible-looking reference.
